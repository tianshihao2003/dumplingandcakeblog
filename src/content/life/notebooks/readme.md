# 笔记本使用说明

写新笔记前，先看这张对照表，按"内容是什么"对号入座：

| 你想记的内容 | 放进哪个本子 |
| --- | --- |
| 每天的复盘：今天做了什么、感想、明天计划 | 每日总结 |
| 一段想写下来的话：随笔、长文、自我提醒、突然的感悟 | 随笔 |
| 关于宝宝的一切：和宝宝的日常、承诺、想一起做的事 | 我和宝宝的日常 |
| 听喜马拉雅听到的好文章、听书笔记 | 喜马拉雅 |
| 博客相关的事：插件问题、博客想法 | 博客记录 |

几个提醒：

- 每本只有一个用途，写的时候不用纠结，内容属于哪类就进哪本。
- 条目的日期写在文件头部 `date` 字段里，页面按日期倒序展示，文件名怎么写都行。
- 拿不准的两类最容易搞混的是"跑步/健身"——如果是当天复盘的一部分就写进每日总结，如果是专门想记的运动感想就写进随笔。
