## 「全部文章」目录只在文章阅读页加载

- 站长要求：全部文章只在文章阅读页需要，其他页面都不需要。
- 目录由 `PostDirectoryList`（365 条树状列表）渲染，原先挂在右下角悬浮坞（`UnifiedDock.astro`）里，
  等于**每一页的 HTML 都背着整棵目录树**——实测 /projects/ 页 856 KB，其中光是目录条目的
  `data-post-slug` 就占掉约 257 KB，改成只在文章页渲染后降到 599 KB。
- 现在：悬浮坞里用服务端判断 `isPostDetailPage`（`/posts/<slug>/`；列表页 `/posts/` 与分页 `/posts/2/`
  用负向先行断言排除）包住渲染，非文章页的 HTML 里不再有目录。
- **不需要客户端补拉**：`#unified-dock` 本身就在 `#swup-container` 内，SPA 导航时悬浮坞整块被 Swup
  换成新页面的版本、内联脚本随之重跑，所以首页点进文章页时目录、当前文章高亮、「文章」按钮都是自然就位的。
- 移动端文章页工具栏与右侧栏的 `PostDirectory` 组件不受影响，照旧。

> 验证：pnpm check 0 错误；pnpm build 通过。产物断言：首页 / 文章列表 / 导航 / 分类 / 友链 / 动态 /
> 影视游戏 / 归档 / 相册 共 9 个非文章页 `data-post-slug` 均为 0；365 篇文章页全部保留目录且渲染在
> `#dock-drawer-posts` 抽屉内。浏览器实测（生产预览 4322）：文章页整页加载 → 目录 365 条 + 当前文章高亮；
> 首页 → 目录 0 条、按钮隐藏；首页点文章（SPA）→ 目录 365 条就位；点「文章」按钮抽屉正常打开。
