# 时间骨架（基础期，每天照这个走）

```
07:00–07:30  起床、早饭（不碰手机）
07:30–07:50  回忆昨天（不看书）            ← 记忆①  20 分钟
08:30–10:00  听课
10:00–11:30  教材对应章节精读 + 章节刷题
11:30–14:00  午饭 + 午休（睡 20–30 分钟）
14:00–15:00  职测模块方法论
15:00–17:00  职测限时刷题
17:00–19:00  晚饭 + 休息（离开书桌）
19:00–20:00  错题归因 + 回填框架笔记
20:00–20:30  时政
20:30–21:00  默写今天的骨架清单            ← 记忆②  30 分钟
21:00–21:15  过最难记的部分                 ← 记忆③  15 分钟
22:30 前     睡觉
```
