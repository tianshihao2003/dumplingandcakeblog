## 两个概念

| 概念 | 定义 |
| --- | --- |
| 提示词（Prompt） | 引导大模型（LLM）进行内容生成的命令（一句话、一个问题等） |
| 提示词工程（Prompt Engineering） | 通过有技巧地编写提示词，使大模型生成出尽可能符合预期的内容，这一**持续性优化的过程**就叫提示词工程 |

区别在于：提示词是"你说出去的那句话"，提示词工程是"为了拿到好结果而不断打磨这句话的过程"。

它的本质作用是：**引导 AI 思考，约束其输出范围，并明确你期望的结果**。

## 写好提示词的六个要素

以"给高中生讲法国大革命"为例，逐条对照：

| 序号 | 要素 | 示例 |
| --- | --- | --- |
| 01 | 给大模型设定角色与能力 | 你是一名经验丰富的高中历史老师，擅长生动有趣的讲解复杂历史事件 |
| 02 | 明确核心请求与任务 | 请向一位高中生解释法国大革命爆发的主要原因 |
| 03 | 按步骤拆解复杂任务 | 请先概述背景，然后分政治、经济、思想三个方面阐述，每点配一个例子 |
| 04 | 提供输入输出的示例 | 可以参考《人类群星闪耀时》的叙事风格 |
| 05 | 明确要求输出格式 | 请严格按照如下结构输出：…… |
| 06 | 指定风格与语气 | 请使用简洁、口语化、充满热情的语气（避免使用过于学术的术语） |

> [!TIP]
> 六个要素记不住时，可以压缩成三个词：**角色 + 任务 + 要求**。实战中不要求每次都写全，但"任务"和"要求"至少要清楚。

## 完整示例

把六个要素组合起来，就是一段可以直接发给大模型的提示词：

```text
你是一名经验丰富的历史老师，擅长用生动有趣的方式讲述复杂的历史事件。现在，请完成以下任务：

1. 核心任务： 向一位高中生解释法国大革命爆发的主要原因。

2. 表达要求：
    语气与风格： 使用简洁、口语化、充满课堂热情的语气，避免学术黑话。整体叙事可以借鉴《人类群星闪耀时》中对历史关键时刻的描写手法，富有画面感和戏剧性。
    内容禁忌： 聚焦于原因分析，不要罗列冗长的日期和事件过程表。

3. 内容与结构要求：
   开头： 先用一段话，生动描述革命前法国社会的总体氛围和紧张感（即背景概述）。
   主体： 分别从政治、经济、思想三个层面阐述直接原因。每个层面提炼2个关键点，并为每个关键点配1个具体、有说服力的史实例子。
   结尾： 提供一个帮助学生记忆的妙招。

4. 输出格式： 请严格、完整地按照以下框架组织你的回答：
【历史现场氛围】
（在这里写你的背景概述）
【危机根源解析】
政治层面：
  - 关键点1：... 例子：...
  - 关键点2：... 例子：...
经济层面：
  - 关键点1：... 例子：...
  - 关键点2：... 例子：...
思想层面：
  - 关键点1：... 例子：...
  - 关键点2：... 例子：...
【记忆法宝】
（请提供一个巧妙的比喻、口诀或联想图像，将这三大层面串联起来，方便学生瞬间记忆）
```

注意这段提示词的写法特点：**用编号分层次、明确写出"不要什么"、把输出格式的骨架直接给出来**。格式骨架给的越具体，模型的输出就越稳定。

## 在项目里怎么用

在本章的 AI 智能伴侣项目中，提示词工程体现为 `system` 角色的一段话 + 两个占位符：

```python
system_prompt = """
        你叫 %s，现在是用户的真实伴侣，请完全代入伴侣角色。
        规则：
            1. 每次只回1条消息
            2. 禁止任何场景或状态描述性文字
            3. 匹配用户的语言
            4. 回复简短，像微信聊天一样
            5. 有需要的话可以用❤️🌸等emoji表情
            6. 用符合伴侣性格的方式对话
            7. 回复的内容, 要充分体现伴侣的性格特征
        伴侣性格：
            - %s
        你必须严格遵守上述规则来回复用户。
    """
```

其中的 `%s` 由用户输入的昵称和性格填充，这样同一条提示词模板就能生成不同性格的伴侣。
