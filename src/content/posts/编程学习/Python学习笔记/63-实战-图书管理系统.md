## 需求

某社区图书馆要开发一个简单的图书管理系统，支持会员登录、图书借阅、图书归还。

| 功能 | 说明 |
| --- | --- |
| 会员登录 | 卡号 + 密码登录，登录成功后才能使用系统 |
| 借书 | 借阅库存有余量的图书 |
| 还书 | 归还已借阅的图书 |
| 查看我的借阅 | 展示当前会员已借阅的图书列表 |
| 退出系统 | — |

**借阅规则**：普通会员最多借 3 本；VIP 会员最多借 `6 + VIP等级` 本（等级默认 1）。库存不足或已达上限时不能借。

## 类的设计

| 类 | 职责 |
| --- | --- |
| `Book` | 一本书：编号、标题、作者、总数、**可用数量（私有）**；借出/归还/查可用 |
| `Member`（抽象类） | 会员公共部分：卡号、姓名、**密码（私有）**、**借阅列表（私有）**；借书/还书/取密码/取借阅列表；**抽象方法 `get_max_books()`** |
| `NormalMember` | 普通会员：`get_max_books()` 返回 3 |
| `VIPMember` | VIP 会员：多一个 `vip_level`，`get_max_books()` 返回 `6 + vip_level` |
| `LibrarySystem` | 图书馆系统：加载数据、登录、借书、还书、查看借阅、主循环 |

## 抽象类：规定子类必须实现什么

```python
from abc import ABC, abstractmethod

class Member(ABC):          # 继承 ABC（Abstract Base Class）
    ...
    @abstractmethod
    def get_max_books(self) -> int:
        pass                # 只有声明，没有实现
```

> [!IMPORTANT]
> **抽象类**是一种只能被继承、不能被直接实例化的类，作用是**规定子类必须实现哪些方法**，强制子类遵守统一的代码规范。Python 里的抽象类需要继承 `abc` 模块的 `ABC`，抽象方法用 `@abstractmethod` 装饰。
> 在这里它的价值是：`Member` 自己说不清"最多能借几本"，但要求每个子类**必须**说清楚。

## 关键代码

### 图书：私有可用数量 + 借还

```python
class Book:
    def __init__(self, book_id, title, author, total_num):
        self.book_id = book_id
        self.title = title
        self.author = author
        self.total_num = total_num
        self.__available_num = total_num      # 可用数量（私有）

    def borrow_book(self):
        if self.__available_num > 0:
            self.__available_num -= 1
            return True
        return False

    def return_book(self):
        self.__available_num += 1

    def get_available_num(self):
        return self.__available_num
```

### 会员：借书时先查上限，再查库存

```python
class Member(ABC):
    def borrow_book(self, book: Book):
        # 1. 达到最大借阅数量就不给借
        if len(self.__borrowed_books) >= self.get_max_books():
            print("借阅失败，您的借阅数量已达到最大限制！")
            return False
        # 2. 书籍还有余量才借
        if book.borrow_book():
            self.__borrowed_books.append(book)
            print(f"{self.name} 已成功借阅图书 {book.title}")
            return True
        else:
            print(f"借阅失败，图书 {book.title} 已被借完！")
            return False
```

### 两种会员：用多态实现"上限不同"

```python
class NormalMember(Member):
    def get_max_books(self) -> int:
        return 3


class VIPMember(Member):
    def __init__(self, member_id, name, password, vip_level):
        super().__init__(member_id, name, password)
        self.vip_level = vip_level

    def get_max_books(self) -> int:
        return 6 + self.vip_level
```

### 系统：从 JSON 加载数据（按卡号前缀判断会员类型）

```python
class LibrarySystem:
    def __init__(self):
        self.books = {}                       # {"AI001": Book对象, ...}
        self.members = {}                     # {"V001": Member对象, ...}
        self.current_member: Member | None = None
        self.load_books_data()
        self.load_members_data()

    def load_members_data(self):
        with open("data/members.json", "r", encoding="utf-8") as f:
            members_data = json.load(f)
            for member in members_data:
                if member['卡号'].startswith('N'):
                    self.members[member['卡号']] = NormalMember(member['卡号'], member['姓名'], member['密码'])
                elif member['卡号'].startswith('V'):
                    self.members[member['卡号']] = VIPMember(member['卡号'], member['姓名'], member['密码'], member['会员等级'])
```

数据结构对应关系：`books.json` 里是 `[{"编号","标题","作者","数量"}, ...]`，`members.json` 里是 `[{"卡号","姓名","密码","会员等级"}, ...]`（普通会员没有"会员等级"字段）。

### 主循环

```python
def run(self):
    if self.login():                 # 登录成功才进菜单
        while True:
            print("1. 借阅图书  2. 归还图书  3. 查看借阅  4. 退出系统")
            choice = input("请选择操作(1-4): ")
            match choice:
                case "1": self.borrow_book()
                case "2": self.return_book()
                case "3": self.show_borrowed_books()
                case "4":
                    print("退出系统, Bye Bye ~")
                    break
                case _: print("无效的选项，请重新选择！")
```
