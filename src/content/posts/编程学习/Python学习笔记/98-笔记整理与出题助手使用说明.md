# 笔记整理与出题助手使用说明

> 这是**使用手册**：讲怎么跟这个助手说话、会得到什么结果、文件都放在哪。
> **规则细节不在这里**——规则写在《[笔记整理规范](/posts/编程学习/python学习笔记/99-笔记整理规范/)》里，本文不重复，避免两份规则对不上。

## 一、它是什么

ZCode 里有一个叫 `note-organizer` 的技能，负责两件事：

1. **整理笔记**：把学习资料（视频截图、PPT、PDF、手写照片、课程代码）变成规范的 Markdown 笔记，写进博客仓库。
2. **出题与批改**：给每篇笔记出练习题、生成可直接运行的练习文件、批改你写的代码、把错题挑出来重做。

它的执行入口是 `.agents/skills/note-organizer/SKILL.md`，那个文件只是指针，**不用手动改**。

## 二、怎么跟它说话

| 你说 | 它做什么 | 产出在哪里 |
| --- | --- | --- |
| 「整理成笔记」「记到笔记里」（附图片/PPT/PDF） | 读资料 → 查证 → 写成规范笔记 | `src/content/posts/编程学习/Python学习笔记/NN-笔记名.md` |
| 「补全某篇笔记」「追加到 26」 | 补充或追加到既有笔记，加 `updated` | 同上 |
| 「**出题 26**」 | 在笔记末尾写题（填空组 + 裸写题 + 折叠提示），并生成练习文件 | 笔记末尾 + 练习库 |
| 「**批改 26**」 | 真的运行你写的代码，把批改结论写回笔记里每道题下面；错题打 ❌ | 笔记里对应题目下 |
| 「**重做错题 26**」 | 挑出带 ❌ 的题，生成**不带提示、不带答案**的重做文件 | `retry_NN_主题.py` |
| 「看答案 26 第3题」 | 把参考答案发给你 | 聊天里 |
| 「规范里加一条 X」 | 改《笔记整理规范》，并同步本文 | 规范文章 |

编号（`26`）就是笔记文件名开头的两位数字；也可以直接说笔记名，比如「出题 Python3 集合」。

## 三、一次完整流程长什么样

以「26-Python-with关键字」为例：

1. **学完一章**：把 PPT/截图发给它 → 得到 `26-Python-with关键字.md`，含概念、代码、易错点提示。
2. **说「出题 26」**：笔记末尾多出一个 `## 练习题` 区块——
   - 一、回忆填空（8~10 个空，把这篇的所有 API 串成速查表，答案折叠）
   - 二、裸写题 3 道（**只给需求，不给 API 提示**；想不起来可以逐级展开折叠的三级提示）
   - 三、综合题 0~1 道（分步引导）
   同时在 `Daily-Learning/python/26-Python-with关键字/` 生成 `test_01_xxx.py`，里面只有题目和「在下面写你的代码」，**没有答案**。
3. **在 PyCharm 里做题**：打开练习文件，在 `# 在下面写你的代码：` 下面写。已经写过的代码它不会覆盖，重新出题只刷新题目部分。
4. **说「批改 26」**：它会实际运行你的代码，然后在笔记里每道题下面写批改结论——通过的打勾，错的地方写清**正确的用法**（比如「`!= None` 应写成 `is not None`：前者比值，后者比身份」）。做错的题在题目行标 ❌。
5. **说「重做错题 26」**：为带 ❌ 的题生成 `retry_01_xxx.py`（这轮不给任何提示），重做通过后把笔记里的 ❌ 去掉。

## 五、规则想改怎么办

- **改规则只改一处**：《笔记整理规范》。技能是它的指针，改了规范不用动技能。
- 也可以直接跟我说「规范里加一条……」，我会改规范文章，**同时更新本文**（功能有变化时）。
- 本文末尾的「更新记录」会记下每次功能变化，方便你回头看它是什么时候变的。

## 六、常见问题

**为什么练习文件里没有答案？**
避免边做边瞄。答案在笔记的折叠块里，做完再点开对照；也可以说「看答案 26 第3题」让它发给你。

**为什么题目不像以前那样直接给出方法名？**
以前那种 `-> list.append(元素)` 等于把答案写在题干里，照着抄一遍记不住。现在改成折叠的三级提示（思路 → 方法名 → 骨架），先自己想，实在想不出来再逐级展开——展开本身也是学习信号。

**题量太少会不会覆盖不全？**
覆盖面交给「回忆填空题组」：一道题里 8~10 个空，把这篇笔记的 API 全串一遍；深度交给裸写题；再难的用综合题串起来。出完题还会对照知识点清单逐条检查有无遗漏。

**旧的题（2026-09-18 之前出的）会和现在不一样吗？**
会。旧题的提示更直接、答案写在练习文件里、目录按标题命名——它们保留原样不改造，新题才按新规范。
