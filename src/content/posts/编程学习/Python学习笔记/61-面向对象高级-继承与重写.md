## 继承是什么

继承描述的是**两个类之间的关系**：子类继承父类，就可以获取到父类中的属性和方法。

为什么要用它？看这个例子：燃油车和电车都需要"启动、停止、行驶"，如果各写一遍就是重复代码。把公共部分抽出来做成 `Car`（父类），两种车继承它即可：

```python
class Car:
    def __init__(self, brand, model, color):
        self.brand = brand
        self.model = model
        self.color = color

    def start(self):
        print(f'{self.brand} {self.model} 正在启动...')

    def stop(self):
        print(f'{self.brand} {self.model} 停止行驶...')

    def run(self):
        print(f'{self.brand} {self.model} 正在行驶...')


class FuelCar(Car):        # 子类(父类)：括号里写父类的类名
    pass


class ElectricCar(Car):
    pass
```

```python
c1 = FuelCar("BMW", "X5", "黑色")   # 子类不需要自己写 __init__，直接用父类的
c1.start()   # BMW X5 正在启动...
c1.run()     # BMW X5 正在行驶...
```

> [!IMPORTANT]
> 子类会把父类**公共的（非私有）**属性和方法继承下来，**私有的继承不到**。所以父类里 `self.__owner` 这类私有属性，子类无法直接使用（可以先调父类的 `get_owner()` 取脱敏值）。

## 方法重写

重写是指子类继承父类后，如果父类中的方法不满足需求，可以在子类中**重新定义一个同名方法**，从而用子类的实现替换父类的实现。

```python
class Car:
    def charge(self):
        print(f'{self.brand} {self.model} 正在补充燃料...')


class FuelCar(Car):
    def charge(self):
        Car.charge(self)                       # 方式二：父类名.方法名(self)
        print(f'{self.brand} {self.model} 正在加油...')


class ElectricCar(Car):
    def charge(self):
        super().charge()                       # 方式一：super().方法名()
        print(f'{self.brand} {self.model} 正在充电...')
```

| 问题 | 答案 |
| --- | --- |
| 什么是重写？ | 在子类中重新定义与父类**同名**的方法，用子类自己的实现替换父类的实现 |
| 如何在子类里调用父类的方法？ | 方式一 `super().方法名()`；方式二 `父类名.方法名(self)` |

## 多继承与 MRO

多继承指的是一个子类**同时继承多个父类**（会把多个父类中非私有的属性和方法都继承下来）。

```python
class XiaomiAiDriving:                     # 智驾系统
    def __init__(self, version="V1.0"):
        self.version = version

    def run(self):
        print(f'使用智驾系统{self.version}正在行驶...')


class SmartCar(Car, XiaomiAiDriving):      # 同时继承两个父类
    def __init__(self, brand, model, color, version="V1.0"):
        Car.__init__(self, brand, model, color)
        XiaomiAiDriving.__init__(self, version)

    def run(self):
        Car.run(self)                      # 两个父类的 run 都想用，就都显式调用
        XiaomiAiDriving.run(self)
```

> [!NOTE]
> **MRO**：Method Resolution Order（方法解析顺序）。当一个类继承了多个父类时，**默认优先使用第一个父类中的同名属性或方法**；查看顺序可以用 `类名.__mro__` 属性或 `类名.mro()` 方法。
