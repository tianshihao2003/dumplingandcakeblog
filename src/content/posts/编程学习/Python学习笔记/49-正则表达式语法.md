## 两张表记住正则语法

### 字符类：匹配"什么"

| 表达式 | 描述 |
| --- | --- |
| 普通字符 | 字母、数字、汉字及大多数字符，直接匹配自身 |
| `.` | 匹配任意一个字符（除 \n） |
| `\d` | 匹配数字 0-9 |
| `\D` | 匹配**非**数字 |
| `\w` | 匹配单词字符，即 a-z、A-Z、0-9、_（默认还含其它语言字符） |
| `\W` | 匹配非单词字符 |
| `\s` | 匹配空白字符，即空格、\t |
| `\S` | 匹配非空白字符 |
| `[38]` | 字符集：匹配 3 或 8 |
| `[^38]` | 反向字符集：匹配**非** 3、8 |
| `[3-9]` | 范围：匹配 3 到 9 |

### 量词与定位：匹配"几次"、"在哪"

| 表达式 | 描述 |
| --- | --- |
| `*` | 出现任意次（0 次或无数次） |
| `+` | 至少出现 1 次 |
| `?` | 至多出现一次（0 次或 1 次） |
| `{m}` | 出现 m 次 |
| `{m,}` | 至少出现 m 次 |
| `{m,n}` | 出现 m 到 n 次 |
| `|` | 或，匹配左右任意一个表达式 |
| `()` | 将括号中的字符作为一个**分组** |
| `^` | 匹配字符串**开头** |
| `$` | 匹配字符串**结尾** |

> [!TIP]
> 同一个手机号规则可以有多种写法，严格程度不同：`1[3-9]\d*`（后面随便几位）→ `1[3-9]\d{9}`（正好 9 位）→ `^1[3-9]\d{9}$`（**整串**必须是一个手机号）。

## 实战示例

```python
import re

s1 = "18809090000是我的手机号，188开头的；我的另一个手机号是15500008888，两个QQ号分别是1259989092和13809091293821，邮箱为python666@163.com，请给我发邮件。"

print(re.findall(r"188\d{8}", s1))     # {8} 正好 8 位数字
print(re.findall(r"155\d{6,10}", s1))  # 6 到 10 位
print(re.findall(r"1[38]\d{8}", s1))   # 第二位是 3 或 8
print(re.findall(r"1[3-9]\d{8}", s1))  # 第二位是 3 到 9
print(re.findall(r"^1[3-9]\d{9}$", s1)) # 整串必须是一个手机号 → 匹配不到
print(re.findall(r"\w+@\w+\.\w+", s1)) # 提取邮箱
```

## 分组：findall 会返回元组

给正则的一部分加 `()`，`findall` 返回的就不再是整串，而是**每个分组各占一个位置的元组**：

```python
s2 = "现在的时间是2026-02-06 10:05:25, 今天的天气还可以"

print(re.findall(r"\d{4}-\d{2}-\d{2}", s2))          # ['2026-02-06'] 整串
print(re.findall(r"(\d{4})-(\d{2})-(\d{2})", s2))     # [('2026', '02', '06')] 分组
```

> [!NOTE]
> `\w` 默认会匹配中文等"其它语言字符"。只要英文数字时加第三个参数 `re.ASCII`：`re.findall(r"\w+", s, re.ASCII)`。
