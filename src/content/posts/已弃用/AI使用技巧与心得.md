## 笔记学习流程

### 1. 自动添加知识点
在使用 AI 的时候可以让 AI 自动添加不会的知识点到对应笔记位置。

### 2. 自动生成练习题
学完一个知识后，让 AI 在笔记末尾生成练习题：
- 每道题附带**复选框** `- [ ]`，做完改成 `- [x]`
- 每道题附带**参考答案**
- 题目针对 Windows 环境，代码可以直接运行

### 3. 同步创建练习文件
AI 会在 `E:\GithubProgect\MyRunProject\Daily-Learning\python` 下创建以笔记名命名的子文件夹，并在其中创建对应的 `.py` 文件：
- 子文件夹命名：笔记标题（如 `Python3数据类型转换`）
- 文件命名格式：`test_序号_知识点.py`
- 例如：`python/Python3数据类型转换/test_01_implicit.py`
- 每个文件包含题目要求和代码框架，可直接运行

### 4. 练习题格式规范
每道练习题的格式如下：

```python
# ============================================
# 题目X：题目名称
# ============================================
# 完成以下操作：
# 1. 题目要求 |---知识点：方法/知识点---|
# 2. 题目要求 |---知识点：方法/知识点---|
# ============================================
# 在下面写你的代码：


# ============================================
# 参考答案（写完后取消注释对比）
# ============================================
# 代码...
```

**知识点提示的作用：**
- 在每个题目后用 `|---知识点：方法---|` 标注需要用到的方法
- 做题时不用一直翻答案，直接看提示就知道用什么方法
- 方便记忆和巩固知识点

### 5. 使用方式
告诉 AI：
```
出题
```
然后 AI 会自动：
1. 在笔记文件末尾添加练习题（带知识点提示）
2. 在 Daily-Learning/python 文件夹下创建对应的 .py 文件

### 6. 练习题格式规范
根据题目类型和位置选择不同的格式：

**笔记中的普通小练习题：**
```markdown
- [ ] **1. 题目名称**
  题目要求...
  
  **知识点：** 方法/知识点说明
  
  **参考答案：**
  ```python
  代码...
  ```
``` markdown

**练习文件中的普通小练习题：**
```python
# 1. 题目要求 |---知识点：方法---|
# 2. 题目要求 |---知识点：方法---|
```

**综合练习题/项目案例（笔记）：**
```markdown
## 案例名称
### 案例需求
1. 需求1
2. 需求2

### 分步引导
**第一步：步骤名称**
- 步骤说明和提示

**第二步：步骤名称**
- 步骤说明和提示

### 涉及知识点
| 知识点 | 应用 |
|--------|------|

### 参考答案
代码...
```

**综合练习题/项目案例（练习文件）：**
```python
# ============================================
# 第一步：步骤名称
# ============================================
# 步骤说明和提示
# ============================================
# 在下面写你的代码：

# ... 以此类推 ...

# ============================================
# 完整参考答案（写完后取消注释对比）
# ============================================
```

**格式选择原则：**
- 笔记中的普通小练习题：用 `**知识点：` 格式
- 笔记中的综合练习题：可以用分步骤引导
- 练习文件中的普通小练习题：用 `|---知识点：方法---|` 格式
- 练习文件中的综合练习题：必须用分步骤引导

### 6. 笔记 Frontmatter 规范
每次修改笔记时，确保 frontmatter 包含以下字段：

```yaml
---
title: 笔记标题
published: 2026-09-15
tags:
  - Python
description: 一句话概括笔记内容
---
```

**description 要求：**
- 用一句话概括笔记的核心内容
- 不要太繁琐，简洁明了
- 例如："Python3 列表的创建、访问、增删改查等基本操作"

### 7. 出题质量规范
出题后必须检查以下几点：

**检查清单：**
- [ ] 覆盖文件中的核心知识点
- [ ] 难度循序渐进（基础→进阶）
- [ ] 知识点提示准确有用
- [ ] 参考答案正确可运行
- [ ] 题目贴近实际使用场景
- [ ] 不出超纲知识点的题目
- [ ] 新学的知识点要解释清楚作用和用法

**常见遗漏：**
- 文件中提到的运算符（如 `in`、`for`）
- 文件中提到的内置函数
- 文件中提到的特殊语法（如元组单元素逗号）

**超纲检查：**
- 用到之前学过的知识点（如 `if`、`for`、列表等）是允许的
- 用到当前文件没讲的知识点（如 `class`、`__init__` 等）需要加详细说明
- 如果知识点太超纲，建议用户先跳过，等学完后再回来做

**新知识点解释规范：**
- 在题目中用 `说明：` 或 `注意：` 解释新知识点
- 解释清楚这个知识点是什么、怎么用、为什么用
- 如果知识点太复杂，可以建议用户先跳过

**操作流程：**
1. 仔细阅读文件内容，列出所有知识点
2. 设计题目覆盖所有知识点
3. 检查题目中是否有超纲知识点
4. 对超纲知识点添加详细说明
5. 出题后对照文件检查是否有遗漏
6. 如有遗漏，及时补充题目
