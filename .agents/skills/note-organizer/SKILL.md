# 讲义同步 / 作业迁移 / 出题 / 批改

## 核心原则

**只做被点名的那一件事。** 不整理笔记、不生成大纲——这两件事用户自己做。

## 能力只有四个

| 能力 | 触发说法 | 产物 |
| --- | --- | --- |
| ① 同步讲义 | 「同步讲义」「下载今天的讲义」 | 更新 `50-归档/下载下来的飞书讲义/` |
| ② 迁移作业 | 「整理 day10 的作业」 | `70-练习题/作业题/<同名>.md`；作业特殊时同时出 `70-练习题/AI作业补充题/<同名>.md` |
| ③ 出题 | 「出 day10 的题」「加练」 | `70-练习题/AI生成加练题/<同名>.md` |
| ④ 批改 | 「批改作业」「批改 day10」 | 就地改上面三个目录里的同名文件 |

## 落点（只有这三个）

| 目录 | 放什么 |
| --- | --- |
| `学习笔记/编程学习/python/70-练习题/作业题/` | 作业原文 + 空答案位 + 折叠参考答案 |
| `学习笔记/编程学习/python/70-练习题/AI作业补充题/` | **迁移作业时**，作业内容特殊（没有具体题面）才生成，文件名与作业同名 |
| `学习笔记/编程学习/python/70-练习题/AI生成加练题/` | **要加练时**才生成的补充练习 |

这三个子目录不存在时可以创建，其余目录一律不新建。

禁止动：`30-笔记/`（含文档记录、概念卡、知识导图）、`20-代码片段`、`10-卡点本`、`40-日志`、`60-面试题`；也禁止改名、改编号、删除任何文件。

> 常见借口：「顺手把笔记也整理了」「大纲一起生成吧」「旧的顺手也整理了」——一律不做。违反字面＝违反要求。

## ① 同步讲义

两个独立导出根，**各自跑各自，不要合并到一个目录**（`sweepStrayMd` 会删掉不属于本次范围的 `.md`）：

```powershell
# 讲义（17 篇，来自「黑马学习知识库」的「讲义」节点）
node E:\GithubProgect\MyRunProject\feishu-Export\src\cli.mjs export "https://ocn0tgqr5oz2.feishu.cn/wiki/MoVlwtdphiAitikpq9LceygAnNd" -o "E:\GithubProgect\MyRunProject\dumplingandcakeblog\src\content\学习笔记\编程学习\python\50-归档\下载下来的飞书讲义\讲义导出"

# 作业与参考答案（25 篇，来自班级 wiki 的「作业」节点）
node E:\GithubProgect\MyRunProject\feishu-Export\src\cli.mjs export "https://wcn4b8bw7lqr.feishu.cn/wiki/BeauwojutiFRvLkViSwcioI5nhe" -o "E:\GithubProgect\MyRunProject\dumplingandcakeblog\src\content\学习笔记\编程学习\python\50-归档\下载下来的飞书讲义\作业导出"
```

- **不要加 `--scope space`**：会把整个知识库（vibcoding、java 等无关目录）拉进来
- 未变更的文档秒跳过；报 `131006 permission denied` 是飞书授权问题

### 同步后必须自检（只看当天，有缺失才提醒）

跑完不立刻结束，**只检查当天（dayNN）要用的内容**；其它天缺什么都不用管、不用汇报。

| 检查项 | 怎么查 |
| --- | --- |
| 导出失败数 | 命令输出的「失败 : N」 |
| `_errors.md` | 有内容就贴出来 |
| 当天三件套 | 讲义 / 作业 / 参考答案三个文件都在 |
| 正文完整性 | 当天文件里搜 `内嵌电子表格（v1 不转换）`、`不支持的块类型`、`画板（v1 不导出视觉内容）` |
| 图片 | 当天文件引用的 `![[...]]` 能在 `static/` 里找到 |

- 任一项不过，**先重跑一次同样的导出命令**
- 还缺就判断是不是「文档没变、但静态资源被删过」——这种增量同步永远跳过，**删掉对应导出根的 `.feishu-export-manifest.jsonl` 强制全量重下**，再复查
- 仍然缺的只报告当天这篇：缺哪块、几处、要回飞书截图还是手动补。**不要自己补内容、不要猜**
- 缺的是当天要用的内容，就先问要不要继续；历史天不用提

## ② 迁移作业

### 输入

| 资料 | 路径 |
| --- | --- |
| 讲义 | `下载下来的飞书讲义/讲义导出/讲义/dayNN. ….md` |
| 作业 | `下载下来的飞书讲义/作业导出/作业/dayNN. ….md` |
| 参考答案 | `下载下来的飞书讲义/作业导出/作业/作业参考答案/dayNN-参考答案.md` |

dayNN 文件不存在或内容与作业明显对不上时，先问一句，不猜、不编。

### 文件名

和 `30-笔记/文档记录/` 里那天的笔记同名（`10-AI应用实战功能实现.md` → `作业题/10-AI应用实战功能实现.md`）；那天还没写笔记就用 `NN-主题.md`，NN 取讲义天号补零。

### 整理规则

- **只迁已经学完的那一天**，后面没讲的作业不提前搬——线上文档还会改
- 题目顺序、题号、原始需求说明**一字不改**，代码块、表格、响应示例全部保留
- **小问拆到「能独立写一份答案」的粒度**：`### 1.1`、`### 1.2`（作业号.小问号，原文自带编号就沿用），每个小问各有勾选框、答案块、参考答案折叠、批改位
- **不拆的情况**：同一次作业的操作步骤（做完第 1 步才能做第 2 步，最后只交一份代码），整题一个小节
- 参考答案按小问切开，每个折叠块只放那一个小问的代码
- 参考答案对不上某题写 `[待补充]`，**绝不自己写答案**
- 导出丢失的表格（`内嵌电子表格（v1 不转换）`）保留原行并加 `[待补充]`
- 作业只有「把课上代码敲一遍」这类要求时，照原样记一条勾选项，再按「③ 出题」的 A 类拆成案例实操题，写到 `AI作业补充题/<同名>.md`，并在参考答案处留一行指向它

### 单题形状

```markdown
### 1.1 <小问标题>

**题目**

<原题面，原样粘贴>

- [ ] **我的答案**

```python

```

> [!success]- 参考答案
> ```python
> <参考答案原文>
> ```

**批改**

（待批改）
```

- 勾选框就写在 `我的答案` 前面，整行 `- [ ] **我的答案**`；用户粘完答案顺手就能勾
- 完成状态写 `- [x] **我的答案**`

## ③ 出题

两类题，落到不同目录，**触发条件也不同**：

### A. 案例实操题 → `AI作业补充题/`

**只在迁移作业时触发**，而且是作业内容特殊才写：作业写的是「把课上所有案例代码全部搞定」「把课堂代码搞明白」这种**没有具体题面**的要求时，把它拆成能动手的题。

- 文件名与当天的作业文件**同名**
- 素材只取**当天讲义里的课堂案例**
- 可以一个案例一道题，也可以几个相关案例合并成一道应用题；能合就合
- 题面只给**需求**（做什么、什么方式、输入输出长什么样、验证什么现象），不给代码
- 参考答案 = 讲义代码整理版（补 import、可运行），放折叠块
- 标题用 `## 案例1：<一句话>`、`## 案例2：…`
- **只出实操题**：填空、选择、名词解释一律不出；纯概念内容不硬凑成代码题
- 写完在作业文件那题的参考答案处留一行指向它

### B. 加练题 → `AI生成加练题/`

**只在被要求「出 day10 的题」「加练」时触发**，文件：`AI生成加练题/<与笔记同名>.md`

五道题，四级梯度：

| 级 | 考什么 |
| --- | --- |
| L1 照抄 | 讲义原例换数据重敲 |
| L2 默写 | 只给需求不给代码 |
| L3 变体 | 改需求、加约束 |
| L4 组装 | 当天 + 之前知识点拼一个小场景，题面写明用到哪几个知识点 |

- 题面不出现 API 名、不给答案级提示
- 每题 `- [ ] **我的答案**` + 空代码块
- 每题末尾折叠参考答案 `> [!success]- 参考答案`

## ④ 批改

先看 `作业题/`、`AI作业补充题/`、`AI生成加练题/` 里有没有当天的同名文件，有哪个批哪个，都有就都批。只改这三处：

1. 用户的代码一字不删、不改写
2. 错题在题目标题行末尾加 `❌`；全对加 `✅`
3. 「**批改**」下的 `（待批改）` 整段替换成结论：**第一行固定 `- [ ] ❌ 有问题`**（错题）或 `✅ 正确`（全对），后面写 错在哪 → 正确写法 → 一句话原因
   - 「❌ 有问题」前面必须带勾选框：用户改好后自己勾成 `- [x] ❌ 有问题`，**不要替他勾**
4. 批完把这题的题面和答案收起来，默认折叠：
   - 题面整段包进 `> [!question]- 题目`（每行前加 `> `）
   - 答案代码块包进 `> [!example]- 我的答案`（每行前加 `> `）
   - `- [x] **我的答案**` 留在折叠块外面
   - 已折叠的参考答案不动
5. 只折批过的那几题，没批的保持展开

```markdown
### 1.1 合并三个列表，去重后升序输出 ✅

- [x] **我的答案**

> [!question]- 题目
> ...

> [!example]- 我的答案
> ```python
> ...
> ```

> [!success]- 参考答案
> ```python
> ...
> ```

**批改**

✅ 正确
```

## 回报

三行以内：写了哪几个文件、题目数量、纠正与存疑清单。

## 明确不做

整理笔记、生成知识导图大纲、复习计划、每日日志、卡点本、代码片段与概念卡、`pnpm build`。

## 文档同步（硬要求）

改了这个技能的任何规则，**必须同时更新** `学习笔记/编程学习/note-organizer 使用说明.md`，保持两边一致；不更新文档等于这次改动没做完。
